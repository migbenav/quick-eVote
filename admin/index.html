2. Unidades y códigos de voto

Cada unidad tiene su porcentaje propio. El código de voto agrupa una o más unidades: cuando ese código vota, se suma el porcentaje de todas sus unidades activas. Deja el código vacío o marca la unidad como inactiva si no debe votar.

Carga masiva desde CSV

Columnas: unidad;descripcion;porcentaje;codigo_voto;contacto;max_votos;activo. Solo unidad y porcentaje son obligatorias. Si no incluyes codigo_voto, cada unidad queda como su propio código de voto. Si un código no existe, se crea automáticamente. Reimportar actualiza las unidades por su código de unidad.
